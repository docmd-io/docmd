# @docmd/plugin-playground

Interactive live code runner and component playground for docmd sites - execute JavaScript in real time with captured console output, live HTML/CSS previews, and zero-config markdown code blocks. Bundled with `@docmd/core`, enabled by default.

````md
```js playground title="Interactive JavaScript"
const greeting = "Hello, docmd!";
console.log(greeting);
```
````

Part of the **[docmd](https://github.com/docmd-io/docmd)** documentation engine.
